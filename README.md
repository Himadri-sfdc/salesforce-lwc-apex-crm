
# Salesforce LWC Apex CRM

A Salesforce CRM project built using **Apex, SOQL, Triggers, and Lightning Web Components (LWC)**. This repository showcases real-world Salesforce automation, validation, and data synchronization scenarios commonly used in CRM applications.

## Features

* Prevent duplicate Contacts using Email and Phone.
* Restrict the number of Contacts per Account.
* Prevent Account deletion when dependent records exist.
* Synchronize Account and Contact data automatically.
* Create Tasks when Opportunities are marked Closed Won.
* Restrict Opportunity creation and amount limits.
* Dynamic SOQL and Aggregate Query examples.
* Parent-child record automation using Apex Triggers.
